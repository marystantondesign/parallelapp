Add the **Dream Revisit experience** to the Dreams feature.

Do not redesign the Dreams list or Dream Detail screens. Only add the Dream Revisit experience flow.

---

REVISIT DREAM ENTRY POINT

On the **Dream Detail screen**, add a button labeled:

Revisit Dream

Tapping this button should begin a guided experience that allows the user to re-enter the dream in a meditative state.

---

DREAM REVISIT PREPARATION SCREEN

After tapping Revisit Dream, open a preparation screen titled:

Dream Revisit

Display explanatory text:

Revisit a previously recorded dream and explore its deeper meaning.

Find a quiet place where you can relax.
This experience works best in a calm, meditative state.

Include a button:

Begin Dream Revisit

---

DREAM REVISIT EXPERIENCE

When the user taps **Begin Dream Revisit**, open a full-screen guided experience similar to Echoes.

Display:

Entering Dream State

Reconnecting with your recorded dream...

Include a subtle animated background such as:

• slow drifting shapes
• soft glowing particles
• gentle breathing animation

These visuals should feel dreamlike and introspective.

---

GUIDED RE-ENTRY TIMER

Display a timer representing the dream revisit session.

Suggested duration:

10 minutes

Example countdown:

10:00
09:59
09:58

This timer counts down as the dream revisit session progresses.

---

EARLY EXIT OPTION

Include a small button labeled:

End Dream Revisit

If the user taps this, show a confirmation modal asking:

End Dream Revisit?

Buttons:

Cancel
End Session

---

SESSION COMPLETION

When the timer ends or the user ends the session early, display:

Dream Revisit Complete

Take a moment to reflect on what you experienced while revisiting this dream.

Automatically transition into the **Reflection Capture interface**.

---

REFLECTION CAPTURE

The reflection screen should match the structure used in other experiences.

Sections:

Audio Reflection
• record voice reflection
• playback interface

Notes
• multiline text field

Philosophical Analysis
• Generate Jungian Analysis button
• Jungian Interpretation displayed as a collapsible accordion

The Save Experience button should remain disabled until the user either:

• records audio
OR
• writes notes

---

STORAGE

Dream Revisit reflections should be stored in the **Experience Logs** system rather than inside the Dreams list.

The original dream remains separate from the revisit experience.
