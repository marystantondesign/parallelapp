1. MEDITATION SESSION IMPROVEMENTS

On the Echoes meditation screen (the screen showing the 15-minute countdown timer):

Add a **subtle animated background visualization**.

This animation should move slowly and smoothly in a calm breathing-like rhythm. Examples include:

• slow expanding light pulses
• gentle shifting gradient colors
• faint moving particles

The animation should be minimal and soothing.

---

Add two small control icons near the top of the screen:

Sound icon

Default state: ON
Tapping toggles to a muted speaker icon
Tapping again turns sound back on.

Flashlight icon

Default state: ON
Tapping toggles the flash effect off
Tapping again turns it back on.

These icons should be small and unobtrusive.

2. AUDIO RECORDING IMPROVEMENTS

On the "Transmission Complete" screen, improve the audio recording system.

While recording, display a **recording timer** showing how long the recording has been active.

Example:

Recording 00:18
Recording 02:41

Allow users to create **multiple recordings** for the same Echoes session.

Each recording should display:

• recording length
• play button
• delete option

Add a button to **Save Recording** after recording finishes.

Saved recordings should appear in a list.

3. ECHOES EXPERIENCE LOG

When the user taps **Save Experience**, do not return them to the Echoes introduction screen.

Instead create a new screen called:

Echoes Log

This screen should look similar to a **dream log or journal list**.

Each entry represents a saved Echoes session.

Each log entry should include:

• Date and time of the session
• Short preview of notes or indication that an audio reflection exists

Example:

Echoes Session
May 4 — 11:42 PM
Audio reflection available

Tapping an entry opens the full session details where the user can:

• read saved notes
• play saved audio recordings
• see the date and time of the session
