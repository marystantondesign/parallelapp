ICON CONSISTENCY

Update the sound toggle icon so that its OFF state matches the flashlight OFF state.

Current behavior:
Sound OFF icon shows a speaker with an X.

BUTTON STATE DESIGN

Flashlight and sound buttons should visually indicate ON vs OFF.

Default state (ON):
• button is filled
• icon appears normal

OFF state:
• button becomes outlined
• icon has a diagonal slash through it
