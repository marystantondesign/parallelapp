Create a **mobile app wireframe structure** for an iOS app called **Parallel**.

Important: focus on **correct mobile app architecture and screen structure**, not final visual styling. The UI can be simple or grayscale. Do not add decorative visual design yet.

This app already has an existing user. Do **not** design onboarding, sign-up, login, or account creation screens.

The app uses a **side navigation menu (hamburger menu)** for primary navigation.

Primary sections in the menu:

• Parallels
• Dreams
• Echoes (NEW – Beta feature)

Design the following **mobile screens** using standard iPhone layout and spacing.

---

SCREEN 1 — PARALLELS (Messaging Center)

This is the main feature of the app. It is **not a feed**. It is a messaging center where the user communicates with alternate versions of herself from parallel universes.

Layout should resemble a **conversation list**, similar to messaging apps.

Each conversation row should include:

• Profile image
• Name (usually Mila)
• Parallel identifier (example: Parallel #84)
• Match percentage (example: 92% match)
• Preview of last message
• Timestamp

Example row:

Mila — Parallel #84
92% match
“Did you end up leaving the design job?”
2h ago

Tapping a row opens a chat conversation.

---

SCREEN 2 — PARALLEL CHAT

A standard messaging interface between the user and another version of Mila.

Elements:

• Conversation header with name and match percentage
• Message bubbles for each participant
• Text input field
• Send button

Messages are between **two versions of Mila**.

---

SCREEN 3 — PARALLEL PROFILE

Accessible from the chat header.

This screen shows information about that parallel version.

Include:

• Profile image
• Name
• Parallel ID
• Match percentage
• Location
• Occupation
• Short life summary

Example:

Mila — Parallel #84
92% match

Location: Barcelona
Occupation: Painter

Short life summary text.

---

SCREEN 4 — DREAMS (Dream List)

This section is a **dream journal**.

Display a list of dreams.

Each row includes:

• Small dream thumbnail image
• Dream title
• Date

Example:

The Blue River
March 4

Tapping a dream opens the dream detail page.

---

SCREEN 5 — DREAM DETAIL

This screen displays a recorded dream.

Sections on the page:

• Dream image
• Dream title
• Full description of the dream
• Symbols identified
• Jungian analysis

At the bottom include a button:

“Revisit Dream”

This will start a guided recall experience.

---

SCREEN 6 — ECHOES (Beta Feature Intro Page)

Echoes is a **new experimental feature**.

This page should look like a **feature introduction / informational page** inside the app.

Include:

Headline:
Echoes — Beta

Short explanation that:

• Echoes is currently in beta
• Select users are invited to participate
• Echoes allows users to enter a meditative trance state
• During this state, users may visualize scenes from their **past lives within this universe**

Include a section explaining preparation requirements:

• Must be used in a quiet, private space
• Lights should be turned off
• User should be lying down comfortably
• Phone camera should be facing the user

Include a main button at the bottom:

“Explore Echoes”

---

SCREEN 7 — ECHOES SESSION

This screen represents the **guided trance experience**.

The interface should be **minimal**.

Include:

• A large animated or abstract visual area indicating meditation or light activity
• Caption text appearing near the bottom of the screen

Captions appear **one sentence at a time**, similar to subtitles, and move upward slightly as new sentences appear (similar to a teleprompter effect).

The captions represent spoken guidance from the Echoes system.

Example guidance text:

“Settle into a comfortable position.”
“Allow the room to remain dark and quiet.”
“The camera flash and tones will help guide you into a meditative state.”
“You may begin to see images or fragments from past lives in this realm.”

No chat bubbles or heavy UI elements should appear on this screen.

---

SCREEN 8 — SIDE NAVIGATION MENU

Design the slide-out menu used to move between sections.

Menu items:

• Parallels
• Dreams
• Echoes (marked as NEW or Beta)

This menu should allow the user to navigate between sections of the app.

---

Important constraints:

• Use **mobile iPhone screen proportions**
• Use realistic mobile layout spacing
• Do not add additional features or sections beyond what is listed
• Focus on **correct app architecture and navigation structure**
