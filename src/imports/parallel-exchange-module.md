Edit the **Parallel Chats conversation screen**. Do not redesign the chat layout and do not change the message interface. Only add the Parallel Exchange feature inside an established chat.

Add a new in-chat module that appears within the conversation thread when enough messages have been exchanged with a parallel.

---

PARALLEL EXCHANGE MODULE

Insert a card-like row in the chat that looks like a tappable feature module.

The row should display:

Parallel Exchange  [Beta]

Use the **same Beta chip style that is already used in the Echoes feature**.

The title **Parallel Exchange** should be centered and bold.

The row should appear like a button that can be tapped to reveal more information.

---

EXPAND / COLLAPSE INTERACTION

When the user taps the **Parallel Exchange [Beta]** row, expand the module to reveal additional content.

The expanded section should display the following text:

You and this parallel have built enough resonance to apply for a temporary exchange experience.

A parallel exchange allows two highly compatible versions of yourself to temporarily experience each other's lives.

Initial exchanges are limited to short durations while compatibility is tested.

Below the description show the duration options:

15 minutes — available
1 hour — locked
24 hours — locked

Then show a primary button labeled:

Apply for Exchange

---

CONFIRMATION MODAL

When the user taps **Apply for Exchange**, open a confirmation modal.

Title:

Parallel Exchange Request

Body text:

You are requesting a temporary exchange with this parallel. Initial exchanges last 15 minutes. Both parallels must approve the request before an exchange can occur.

Buttons:

Cancel
Send Request

---

REQUEST SENT STATE

After the user taps **Send Request**, update the exchange module inside the chat to display:

Request Sent
March 9, 2026

This replaces the Apply for Exchange button and indicates that the request has been submitted.
