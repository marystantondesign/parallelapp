Edit the **existing Parallels section** of the Parallel mobile app design. Do not regenerate the entire app. Only refine and expand the Parallels messaging system.

This is a **messaging platform between alternate versions of the same person (Mila)**. It should behave like a realistic mobile messaging product similar to iOS Messages.

Focus on improving the following screens and adding one new screen.

---

REFINE THE PARALLELS MESSAGE CENTER

The message center should function like a **scrollable conversation inbox**.

Changes to apply:

• The conversation list should contain **20 or more entries** so it clearly scrolls vertically.
• Most names should still be **Mila**, but include a few variations such as **Meela, Míla, Robbie, or Sylvie** to reflect identity divergence across universes.
• Include a **range of match percentages**, not just high matches. Example range: 50%–99%.

Each row should contain:

• Profile avatar
• Name
• Parallel identifier (example: Parallel #84)
• Match percentage (example: 92% match)
• Preview of last message
• Timestamp

Add **unread message indicators** to several rows to make the inbox feel active.

Example rows:

Mila — Parallel #84
92% match
“Did you end up leaving the design job?”
2h ago

Meela — Parallel #18
86% match
“I moved to Lisbon last year.”
(3 unread)

Robbie — Parallel #402
61% match
“You would not believe the path I took.”
Yesterday

Add a **button in the top right corner labeled “More.”**

ADD THE “MORE” DISCOVERY SCREEN

• Avatar

• Parallel identifier
